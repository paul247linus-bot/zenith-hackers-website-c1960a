# Zenith Hackers Intelligence

Website for a London private investigations and ethical hacking firm: service pages, a 50-article blog with visitor articles and comments, an AI chatbot, a floating WhatsApp button and a contact form.

**Tech:** TanStack Start (React 19), Tailwind CSS 4, Netlify Database (Postgres + Drizzle), Netlify AI Gateway (Anthropic), Netlify Forms, Netlify Image CDN.

**Run locally:** `pnpm install` then `netlify dev`.

**Roadmap:** moderation/admin for community content, email notifications for enquiries.
